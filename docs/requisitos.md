# Requisitos del Sistema

El sistema debera permitir el registro de usuarios con sus datos basicos (nombre y matricula).

## Requisitos de Prestamos

El sistema debe controlar el inventario de libros y registrar las fechas de salida y devolucion.



&#x20;## Actualizacion por solicitud del cliente

El sistema debera distinguir tres tipos de usuario: estudiante, profesor y personal administrativo.

Los estudiantes podran prestar hasta 3 libros por 7 dias.

Los profesores podran prestar hasta 5 libros por 15 dias.

El personal administrativo podra prestar hasta 3 libros por 10 dias.
