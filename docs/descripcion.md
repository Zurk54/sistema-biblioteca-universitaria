## Alcance de Usuarios

Además de estudiantes, el sistema también brindará servicio a profesores y personal administrativo.



\## Tipos de usuario



El sistema brindara servicio a estudiantes, profesores y personal administrativo.



Cada tipo de usuario contara con acceso a los servicios de prestamo de acuerdo

con las politicas definidas para su categoria.

## Reservas

Cuando un libro no se encuentre disponible, el usuario podra solicitar una reserva.

El sistema registrara el usuario que realizo la reserva y la fecha en que fue solicitada.
